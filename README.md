## 🚀 About Me

I'm a backend-focused engineer passionate about building **scalable systems** and **real-time infrastructure**. Currently pursuing **B.Tech in Information Technology at IIIT Una**.

My engineering journey started with **Android development in Kotlin**, where I built mobile applications and learned how software interacts with users. As my projects grew more complex, I became increasingly curious about the **systems powering them** — APIs, data pipelines, asynchronous processing, and real-time communication.

That curiosity led me to transition toward **backend engineering**, where I now design and build scalable services using **Node.js, Redis, PostgreSQL, and message queues**.

From building a **real-time stock exchange simulator** with sub-100ms order execution to designing **asynchronous worker pipelines** and **AI-driven backend systems**, I enjoy solving problems where **performance, reliability, and scalability** matter.

## 🧠 My Development Journey

### Phase 1️⃣ — **Android Development**
Started with Kotlin and Android Studio, building mobile applications (note apps, drawing tools, productivity utilities). Learned application structure, user experience, and mobile architecture.

### Phase 2️⃣ — **Full Stack Exploration**
Transitioned to web development with **Node.js, React**, and databases. Explored authentication, API design, and data persistence.

### Phase 3️⃣ — **Backend Engineering**

### Phase 4️⃣ — **Production Backend Systems**
Working on real-world systems through internships:
- 📊 Log processing pipelines

- 🎯 Worker-based asynchronous architectures
- 📨 Message queues and distributed task execution
